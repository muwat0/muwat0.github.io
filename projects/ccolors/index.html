ccolors

github

Small CLI tool to extract dominant color palettes from images.

Features

  • JPEG / PNG support
  • Terminal color preview
  • HEX output
  • JSON export
  • No external dependencies

Build

Linux / macOS

mkdir build
cd build
cmake ..
make

Usage

./ccolors image.jpg

Output

  • Prints color swatches + hex
  • Writes palette.json

Dependencies

  • stb_image.h (included)
